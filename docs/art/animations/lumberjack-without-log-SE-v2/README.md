# Dřevorubec SE v2 — zastavený pokus

Stav **2026-09-09: výroba zastavena, neschváleno, neintegrovat**.
Uživatel zpochybnil důvěryhodnost postupu a požádal o prověření Meshy.

Sada obsahuje osm samostatně generovaných obrázků s prostorovými vodítky.
Blender model ve složce guides je pouze pracovní figurína pro vedení póz,
nikoli finální model dřevorubce. Hotové malované snímky nebyly renderovány
z jedné společné animované postavy. Tato metoda stále umožňuje kolísání tvarů.
Osm snímků bylo zabaleno do náhledu; závěrečná vizuální kontrola běžící smyčky
byla přerušením zastavena. Náhled má neprůhledné bílé pozadí.

Meshy je nyní zkoumaná alternativa: vytvořit jeden skutečný model,
ponechat jeho nativní rig a chůzi a následně v Blenderu přímo renderovat
první směr. Žádná Meshy generace ani spotřeba kreditů nebyla zahájena.
Související aktuální dokumentace:
[Image to 3D](https://docs.meshy.ai/en/webapp/image-to-3d),
[rigování](https://docs.meshy.ai/en/api/rigging),
[animace](https://docs.meshy.ai/en/api/animation-library).
